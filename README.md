# GATI CLONER

Clonador de servidores de Discord.

Discord: https://discord.gg/AkE7ksEQKb

## Cómo usarlo

1. Instala las dependencias: `npm i`
2. Copia `.env.example` a `.env` y pon el token de tu cuenta en `TOKEN=` (o déjalo vacío y el programa te lo pide al abrir).
3. Inicia: `npm start` (en Windows también sirve `start.bat`).

En el menú elige **[1] Clonar un servidor en el tuyo**:

1. Crea un servidor vacío desde la app de Discord.
2. Pega el ID del servidor que quieres clonar.
3. Pega el ID de tu servidor vacío y escribe `BORRAR` cuando te lo pida.

El programa arranca en español. Con la opción **[5]** cambias entre español, inglés y portugués.

## Avisos

- Esta herramienta inicia sesión con el token de una **cuenta de usuario** (selfbot). Los Términos de Servicio de Discord lo prohíben, así que tu cuenta podría ser sancionada. Úsala bajo tu propio riesgo y nunca compartas tu token.
- Todo lo que tenga el servidor de destino (canales, roles y emojis) **se borra** antes de copiar. Por eso se recomienda usar un servidor vacío.
